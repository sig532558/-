# 혜성물류 운영 ERP

고백리센터(크리스·LX·로라)와 안성센터(네파)를 한 화면에서 관리하는 웹 프로그램입니다.
여러 명이 동시에 접속해 등록·수정하고, 등급별 권한과 마감 잠금, 수정 이력을 지원합니다.

| 구성 | 내용 |
|---|---|
| 화면 | Cloudflare Pages (정적 웹, 서버 관리 불필요) |
| DB·로그인 | Supabase — 안성센터 프로그램과 **같은 프로젝트** 사용, ERP 테이블은 모두 `erp_` 로 시작 |
| 안성 연동 | 같은 DB의 안성 테이블을 API로 직접 조회 (읽기 전용) + 엑셀 업로드 예비 경로 |
| 프로그램 수정 | GitHub 저장소 → Claude가 수정·업로드 → Cloudflare 자동 배포 |

## 메뉴

- **아침 출고지시 취합** (신규): B2B 브랜드별 판매분·선지시 입력, 전년 같은 요일 자동 비교(수정 가능), 사방넷 파일로 B2C 브랜드별 배송지 건수·수량 자동 집계(개인정보 미저장), 카톡용·엑셀형 이미지와 엑셀 내려받기
- **팀별 KPI · 원가** (신규): Daily KPI Report 양식 입력 또는 엑셀 업로드 → 공정별 원가·생산성·브랜드별 수익성·자동 경고, **관리자 업무일지 원가 자동 반영**
- **신상품 입출고 현황** (신규): 화주 ERP 품번정보·입고현황, WMS 재고현황 업로드 → 브랜드별 입고·출고·정리 현황, 전년 대비, 조치 목록 → TO-DO, 평일 17:30 이후 미업데이트 알림
- **재고 실사** (신규): WMS 재고 현황(현재고 · 미래 발생분 · 누적재고) · 미래 발생분 내역(오픈 · 행사 · 로스 · 반품 창고) · 조별 실사 엑셀 업로드 → 구역별 진행률, 비교 수량(현재고/누적재고/구역별) · 로스 처리 선택, 부족 · 과잉 · 위치 상이 · 미등록, 재실사 TO-DO → 재실사 결과 반영, 대시보드(브랜드 · 년도 · 시즌 · 복종 이너/JK/ACC), 차이 현황 엑셀 7시트(WMS 조정용 포함), 확정
- **시즌 정리 · 선지시** (신규): 이월팀 반기 루틴(F/W 2~6월 · S/S 9~12월) — 매장 재고 · 선지시 엑셀 → 브랜드 × 시즌 × 복종 집계, 이관 기준(정상 · 온라인 · 매장 출고), 소터 · DAS · 수작업 일 목표 · 인원 → 일정표(달력 · 일별 목표/실적) · 인원 투입 계획, 실적 업로드/직접 입력 → 일정 대비 · 인원 증감률 · 일 생산성
- **모든 표 공통 그리드**: 찾기 · 열 숨김/순서 · 정렬 · 열 필터 · 저장된 보기(나만/공유) · 보이는 그대로 엑셀
- **보안 (방화벽 5단계)**: 접속 문(Cloudflare Access) · 로그인 자동 공격 차단 · 관리자 2단계 인증 · 보안 헤더 · 관리자 기능 회사 IP 제한 — 기준정보 설정 › 보안 탭
- **브랜드 관리** (신규): 영문명·코드·다른 이름(사방넷/WMS 표기)·사용 중지, 모르는 브랜드 자동 발견
- **통합 대시보드**: 월 매출·지출·손익(팀별), 전일 마감 출고율, 업무일지 제출 현황, 업무협조 진행률, 안성 API 요약
- **관리자 업무일지**: 팀별 일자별 작업수량·T.O 입력 → 매출(수량×공정단가)·지출(T.O×평균인건비+연장)·손익 자동, 팀장 제출 → 마감 확정
- **일일 마감보고**: B2B 입·출고, 반품, 이월출고, 부자재·사은품, 택배 박스, B2C 화주사, 4개사 완불, WMS 대조, 과·미출 상세 (날짜별 시트 복제 없이 하나의 화면)
- **업무협조 TO-DO**: 업무지원팀이 팀에 할당 → 할당 팀이 접수 · 진행중(진행률 %) · 보류 · 완료 → 완료 순간 할당자에게 **완료 콜사인 팝업 + 알림음**, 새 업무 할당 시 팀원에게 팝업
- **반품 관리**: 일별 반품 박스 수불(진행률 자동), 일별 반품 대장, 행사·선반품, 폐점·홀딩해체, 온라인 반품, 재반송, 불량 회수, 매장 불량
- **입고대행 정산**: 일자·고객사별 박스×1,000원(30박스 이하 30,000원) + 오류 추가금, 세금계산서 목록 엑셀
- **엑셀 일괄 등록**: 기존 엑셀을 그대로 올리면 종류 자동 인식 → 미리보기 → 등록 (중복 없이 최신 값으로 갱신)
- **안성센터 연동**: 안성 테이블 자동 찾기 → 대시보드 표시 항목 지정
- **사용자·등급**: 가입 승인, 등급·담당 팀 지정, 등급별 메뉴×동작(보기·등록·수정·삭제·마감확정·마감해제·업무할당·진행처리) 권한표, 수정 이력
- **개선 요청 · Claude**: 직원 요청 → 관리자가 Claude 지시문 복사 → Claude가 코드 수정 → 자동 배포

## 기본 등급

| 등급 | 범위 | 주요 권한 |
|---|---|---|
| 대표 | 전체 | 전체 열람 |
| 관리자 | 전체 | 모든 권한, 마감 해제, 등급 관리 |
| 업무지원팀 | 전체 | 업무 할당, 마감보고 작성·확정, 업무일지 마감 확정, 반품·정산 등록, 엑셀 등록 |
| 현장 팀장 | 담당 팀 | 자기 팀 업무일지 입력·제출, 할당 업무 진행 처리, 반품 박스 입력 |
| 실무진 | 담당 팀 | 할당 업무 접수·진행률·완료 처리 |

권한표는 **사용자·등급 > 등급·권한**에서 체크로 바꿀 수 있고, 새 등급(예: 반장)도 추가할 수 있습니다.
화면에서 숨기는 것과 별개로 DB 보안(RLS)이 같은 규칙으로 최종 차단합니다.

## 보안 (방화벽 5단계)

설정 › **기준정보 설정 › 보안** 탭에서 상태를 한눈에 확인합니다.

| 단계 | 막는 것 | 설정 |
|---|---|---|
| ① 접속 문 (Cloudflare Access) | 회사 메일 인증 없이는 ERP 주소 자체에 못 들어옴 | Cloudflare Zero Trust › Access › Self-hosted 앱 · 회사 메일 도메인 + 지정 명단 · One-time PIN (보안 탭에 단계별 안내) |
| ② 로그인 자동 공격 차단 | 비밀번호 무작위 대입 | Cloudflare Turnstile 사이트 키 → `site/js/config.js`의 `turnstileSiteKey`, 비밀 키 → Supabase › Authentication › Attack Protection › Captcha |
| ③ 관리자 2단계 인증 | 비밀번호가 새도 관리자 기능 사용 불가 | `05_firewall.sql` 실행 시 관리자 등급 자동 적용 · 첫 로그인 때 휴대폰 인증 앱(Google/Microsoft Authenticator) 등록 · Supabase › Authentication › Multi-Factor에서 TOTP 켜기 |
| ④ 보안 헤더 | 다른 사이트에 끼워넣기·스크립트 주입 | `site/_headers` (Cloudflare Pages가 자동 적용) |
| ⑤ 관리자 기능 회사 IP 제한 | 회사 밖에서 사용자·등급·설정 변경, 마감 해제 | 보안 탭 › 허용 주소 (보기·일반 업무 입력은 어디서나 가능) |

③⑤는 화면이 아니라 DB 권한 함수에서 막으므로 우회할 수 없습니다.

**비상 해제** (회사 인터넷 주소가 바뀌어 관리자 기능이 잠겼을 때) — Supabase › SQL Editor:
```sql
update erp_settings set value = jsonb_set(value, '{admin_ips}', '[]') where key = 'security';
```
관리자가 휴대폰을 잃어버렸을 때: 다른 관리자에게 요청하거나, Supabase › Authentication › Users › 해당 사용자 › MFA factors 삭제.

## 설치 프로그램 (권장)

`설치하기.bat` 을 더블클릭하면 설치 메뉴가 열립니다 (Windows 10/11).

| 메뉴 | 하는 일 |
|---|---|
| 1. 시연 모드 | 설치 없이 이 PC 브라우저로 화면 확인 |
| 2. 운영 설치 ① | Supabase 액세스 토큰으로 ERP 테이블·권한 설치, 로그인 설정, config.js 자동 작성 |
| 3. 운영 설치 ② | Cloudflare Pages 배포 (Node.js 있으면 자동, 없으면 업로드용 압축파일 생성) |
| 4. 설치 점검 | 파일 · DB 접속 · 운영 주소 확인 |
| 6. 업데이트 | `업데이트하기.bat` 과 같음 — 수정 파일 한 번에 적용 |

자세한 화면은 `혜성물류_운영ERP_설치매뉴얼.pptx` 참고. 기록은 `installer/install.log` 에 남습니다.

### 수정 파일 적용 (업데이트하기.bat)

Claude가 보낸 `ERP_수정파일_*.zip` 을 내려받은 뒤 **`업데이트하기.bat` 더블클릭** → Enter.

1. 다운로드 폴더 · 바탕화면에서 가장 최근 수정 파일을 찾음
2. 압축을 풀어 ERP 폴더에 덮어쓰기 (`site/js/config.js` · `installer/settings.json` 은 그대로)
3. 바뀐 SQL만 Supabase에 실행 (파일 지문을 `settings.json` 에 기록 · 처음 한 번은 전체 — 여러 번 실행해도 안전)
4. Cloudflare Pages 배포

Supabase · Cloudflare 토큰은 처음 한 번만 묻고, 원하면 Windows 암호화(DPAPI · 이 PC의 이 Windows 사용자만 풀 수 있음)로 `settings.json` 에 저장합니다.
DB 적용 중 오류가 나면 인터넷 배포는 하지 않고 멈춥니다.

## 직접 설치 순서 (설치 프로그램을 쓸 수 없을 때)

### 1. Supabase에 ERP 테이블 만들기
1. 안성센터 프로그램이 쓰는 Supabase 프로젝트에 로그인
2. 왼쪽 **SQL Editor** → `sql/01_schema.sql` 전체 붙여넣기 → **Run**
3. 이어서 `sql/02_security.sql` → `sql/03_extend.sql` → `sql/04_views.sql` → `sql/05_firewall.sql` → `sql/06_count_season.sql` → `sql/07_returns.sql` → `sql/08_meeting.sql` → `sql/09_anseong.sql` → `sql/10_storage.sql` → `sql/11_notice_pl.sql` → `sql/12_speed.sql` → `sql/13_csdata.sql` → `sql/14_csmerge.sql` → `sql/15_cnt_trash.sql` → `sql/16_cs_alloc.sql` → `sql/17_cs_alloc_close.sql` → `sql/18_np_raw.sql` 차례로 **Run** (추가 기능 · 저장 보기 · 방화벽 · 재고 실사 · 시즌 정리 — 여러 번 실행해도 안전)
4. **Authentication > Providers > Email**: `Confirm email` **끄기** (아이디 로그인 방식)
   - 직원이 직접 사용 신청하게 하려면 `Allow new users to sign up` 켜기
   - 끄고 운영하려면 관리자가 Authentication > Users 에서 `아이디@hyeseong.erp` 형식으로 계정을 만든 뒤, 직원이 로그인해서 사용 신청

> 안성센터 기존 테이블은 건드리지 않습니다. ERP는 `erp_` 테이블만 만들고 씁니다.

### 2. 연결 정보 넣기
`site/js/config.js` 에 **Project Settings > API** 의 URL과 `anon public` 키를 넣습니다.
(service_role 키는 절대 넣지 마세요.)

### 3. GitHub 저장소 만들고 Cloudflare Pages 연결
1. GitHub에 비공개 저장소(예: `hyeseong-erp`) 생성 후 이 폴더 전체 업로드
2. Cloudflare 대시보드 > **Workers & Pages > Create > Pages > Connect to Git** → 저장소 선택
3. Build command: (비움) · **Build output directory: `site`** → Deploy
4. 발급된 주소(예: `hyeseong-erp.pages.dev`)로 접속

### 4. 최초 관리자 지정
1. 접속 → **사용 신청** (아이디·비밀번호·이름)
2. 승인 대기 화면에서 **최초 관리자로 지정** 클릭 (관리자가 한 명도 없을 때만 동작)
3. 이후 직원들은 사용 신청 → 관리자가 **사용자·등급**에서 등급과 담당 팀을 지정하고 승인

### 5. 기존 엑셀 옮기기
**엑셀 일괄 등록**에 지금 쓰는 파일을 그대로 올립니다. 인식 결과를 확인하고 **선택한 자료 등록**.
업무일지 · 일일 마감보고 · 아침 출고지시(월별 시트) · Daily KPI Report · 업무협조(26년10월 형식) · 용차출고 · D+1이상지시 · 출고홀딩 · 오픈/폐점 스케줄 · 부자재출고 · 반품 박스 수불 · 반품 대장 · 입고대행 정산 파일을 인식합니다.

### 6. 안성센터 API 항목 지정
**안성센터 연동 > 안성 테이블 자동 찾기** → 보여줄 테이블을 눌러 표시 이름·날짜 열·합계 열 지정.
안성 테이블의 RLS가 로그인 사용자 읽기를 허용해야 합니다.

## Claude로 프로그램 고치기

1. 직원이 **개선 요청** 등록
2. 관리자가 요청 선택 → **Claude에게 보내기** (지시문 복사)
3. claude.ai 프로젝트 "ERP _업무일지 제작"에 붙여넣기 (GitHub 커넥터가 연결되어 있어야 함)
4. Claude가 코드 수정 → GitHub 업로드 → Cloudflare가 1~2분 안에 자동 배포
5. 요청 상태를 **반영완료**로 변경

## 로컬 모드 (시연·교육)
`config.js`가 비어 있으면 로컬 모드로 열립니다(이 브라우저에만 저장).
시연 계정: `admin / admin1234`, `support`, `leader`, `staff` (비밀번호 `1234`)
