혜성물류(주) 물류관리팀이 주간·월간 회의와 일일 운영에 쓰는 사내 웹앱이다.
- 배포 주소: https://hyeseong-erp.pages.dev
- PC 작업 폴더: `클로드 코드\01. 혜성 회의`
- 회사: 경기도 이천 소재 3PL(패션·의류 물류)

## 작업 원칙

- 모든 답변, 화면 문구, 주석, 커밋 메시지는 한글로 쓴다. 브랜드명만 영문으로 표기한다.
- 최종 결정은 항상 사용자(행님)가 한다. 메뉴 폐기·데이터 삭제·구조 변경처럼 되돌리기 어려운 작업은 실행 전에 먼저 확인받는다.
- 질문은 꼭 필요한 것만 한 번에 모아서 한다. 왕복을 줄이는 것이 우선이다.
- 국내(한국) 물류 실무 기준으로 정확하게 답한다. 수치는 추정하지 말고 실제 데이터로 계산한다.
- 요청받은 범위만 수정한다. 관련 없는 파일 정리나 리팩터링은 하지 않는다.
- 수정 전에 해당 파일을 먼저 읽고, 기존 코드 방식과 화면 구성을 따른다.
- **업데이트 zip(`ERP_수정파일_*.zip`)은 항상 `클로드 코드\01. 혜성 회의` 폴더에 만든다.** 바탕화면에 두지 않는다 (2026-11-24 지시). 이전 zip 들이 모두 이 폴더에 모여 있다.

## 에이전시 운영 (Claude + Gemini + Groq)

- 중심은 Claude, 하위 업무(초안 제작·검증)는 Gemini(무료 버전)와 Groq(무료 API)가 나눠 맡는다.
- Groq는 응답 속도가 빨라 간단한 초안·요약에 우선 쓰고, 멀티모달·깊은 검증은 Gemini를 쓴다.
- Gemini·Groq 호출이 실패하면 멈추지 말고 Claude가 직접 처리한다.
- 자동 작업은 '주간 업무 브리핑'만 켜 둔다. 브리핑은 이 사이트의 회의자료를 기반으로 정리한다.
- 서브에이전트 정의: `.claude/agents/gemini-helper.md`, `.claude/agents/groq-helper.md` (이 프로젝트 전용, 저장소 공통 정의는 루트 동일 파일명).
- Groq API 키는 `.env` 파일(`GROQ_API_KEY`)에 저장하며 저장소에는 커밋하지 않는다.

## 업무 규칙

- **원가 관리**: 팀별로 항목을 추가하고 단가를 수시로 바꿀 수 있어야 한다. 단가는 운영비를 제외한 현장 인건비 관련 단가이므로 전체 공개한다.
- **팀 구성**: 로라팀 메뉴는 필요하다. 별도인원·관리팀 메뉴는 쓰지 않는다.
- **일일 마감 보고**: 자동 집계가 아니라 담당자가 직접 입력한다.
